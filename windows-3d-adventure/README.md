# NOVA: Lost Frontier — 3D Adventure Prototype

An original third-person 3D action/adventure prototype for Godot 4. It uses built-in procedural meshes, so no paid art assets are needed.

## Features
- WASD / arrow-key movement and jumping
- Mouse look and left-click blaster
- Three energy crystals to collect
- Three red sentinels that chase and attack
- Health, crystal counter, victory/defeat messages and restart

## Run on Windows
1. Install Godot Engine 4.x Standard from https://godotengine.org/download/windows/
2. Download this folder using Code → Download ZIP in the repository and extract it.
3. Open Godot Project Manager, click Import, and select project.godot inside this folder.
4. Open the project and press F5 to run.

## Controls
- W A S D or arrows: move
- Mouse: aim / look around
- Left mouse button: fire blaster
- Space: jump
- Esc: release mouse
- R: restart after victory or defeat

## Important
This is an early playable prototype source project, not a precompiled Windows EXE. A Windows build can be exported from Godot using Project → Export after installing Windows Desktop export templates.
